YES/NO counts are the agents' and not comparable between places (NEW rows; stretched topics).

## What we learned
1. The full pass found owner duties the word search missed (search-term test in the log, with its limits). Denver's agent took about 42 minutes by its notification; Frederick's and Boulder's times weren't confirmed (an earlier draft gave figures that can't be traced).
2. It overstates: broad topics stretched to narrow rules, park-only rules, repeats. A second read is needed before any row.
3. A code download isn't current. Denver's was out of date (CB26-0565); Weld Ord. 2026-04 repealed and reenacted chs. 2, 21 and 23 with amendments, and is in the download's citations; Frederick's Land Use Code is a separate 2026 document.
4. Adopted model codes (IPMC, IFC) aren't in any download. Weld deletes the IPMC's maintenance chapters; Frederick and Boulder keep them.
5. Downloads by Taylor work for Municode and frederick.municipal.codes, which block the tools. This is the slow step for the rest of Colorado.

## Not done under Phase 3
Drafted rows; independent check (rule 80); spot-check of five high-stakes rules per place against a second source; Denver's ordinances since the export beyond those read; conflict-with-state-law check on each rule; Boulder County blind pass and septic rules; model-code text.

## Recommendation (for Taylor)
Use the full pass first wherever a code can be got, words as a cross-check; draft rows only after the second read. Projection of length: not yet possible (needs the usage figure and the download time per place).
