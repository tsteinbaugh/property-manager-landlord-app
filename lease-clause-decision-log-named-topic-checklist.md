# Steinoak Clause Library — Consolidated Named-Topic Checklist

**Purpose:** every state-specific finding logged across Colorado (state #1), Wyoming (state #2), Kansas (state #3), Nebraska (state #4, complete), and **North Dakota (state #6, complete)**, consolidated into one list. **Minnesota (state #5) is not yet folded into this file** — a known gap, see "Open items" below. This is the canvass a new state runs against — per the standing rule (KS log, session 7): check every item below explicitly present/absent for the new state, run the canvass twice, don't treat a single pass as sufficient. When a new state is completed, its own findings get folded into this list before the next state starts, so this file keeps growing.

**How to use this:** for each row, determine the new state's status (Present / Confirmed Absent / Not Yet Checked) with a primary-source citation either way. "Not on the list yet" is not an acceptable end state for any row once a state is declared complete.

## Instructions for the next state

1. Copy this table (or work directly from it).
2. For every row, produce Present / Confirmed Absent with a primary-source citation, or explicitly write "Not Yet Checked" if a first pass doesn't get to it — never leave a row silently blank.
3. Run the full canvass a second time before declaring the state complete, independent of the first pass. Nebraska's second pass caught two genuine misses from the first — smoke detector and carbon monoxide alarm statutes. North Dakota's second pass caught several more: a returned-check-fee citation that had been repeated by secondary sources all session but never independently verified, plus a real error in an already-committed clause (a false claim that ordinary lease violations get a cure opportunity ND's statute doesn't actually appear to provide). A second pass that doesn't change anything probably wasn't run independently enough — go back to the full checklist file itself, not just memory of what the first pass concluded.
4. Add any new topics the state's own core-landlord-tenant-statute reading surfaces as new rows in the correct section above (or a new section, if it doesn't fit an existing one) — the next state after this one needs to see it too. Nebraska added four; North Dakota added five (see "New topics added by North Dakota" section above): double-letting-of-a-room prohibition, direct contractual termination rights outside the eviction process, fraudulent-misrepresentation termination right, the payment-method-fee ban, and eviction-record sealing.
5. Update this file's per-state columns and hand it forward.
6. **Watch for overconfident secondary sources.** This project has now hit the same pattern repeatedly and independently — Wyoming (Hemlane), Kansas (a fabricated statute citation), Nebraska twice, and North Dakota twice more: multiple landlord-industry guides citing N.D.C.C. § 14-02.5-07 for a "must accept Section 8 vouchers" rule when the actual operative section was § 14-02.5-02 (§14-02.5-07 is titled "Residential real estate-related transaction," an unrelated provision); and a claim that ordinary ND lease violations get a statutory cure opportunity, which turned out to be unsupported once checked against the same site's own separate eviction-process page. Treat any specific number, penalty, or citation from a non-primary source as unverified until checked against the actual statute text, regardless of how confidently it's stated or how many sources repeat it.
7. **Check adjacent chapters, not just the core act.** Nebraska's smoke-detector and CO-alarm duties, and its bad-check restitution statute, all live outside Chapter 76. North Dakota's smoke-detector duty (§23-13-15, Title 23 Health and Safety), its self-help-eviction damages measure (§32-03-29, Title 32), its bad-check fee cap (§6-08-16, Title 6 Banking), and its housing-discrimination protections (§§14-02.4, 14-02.5, Title 14) all live outside Chapter 47-16 too — the same pattern, now confirmed a fourth and fifth time. A first pass confined to the core act's table of contents will reliably miss real findings.
8. **When a live participant (the person you're working with) can supply primary-source text directly, take it seriously and re-verify against it immediately.** North Dakota's session was substantially strengthened by Taylor providing the complete Chapter 47-16 text directly partway through, plus the enacted text of two specific sections (§47-16-20.1, §32-03-29) that had been stuck as blocked or weak-evidence items for the entire rest of the session. This isn't a substitute for independent verification, but it's a legitimate and often faster path to primary-source confidence than continued guessing at search queries — don't be too proud of the search-only approach to pass up a direct text contribution when it's offered.
