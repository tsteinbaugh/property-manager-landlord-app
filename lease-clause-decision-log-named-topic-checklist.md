# Steinoak Clause Library — Consolidated Named-Topic Checklist

**Purpose:** every state-specific finding logged across Colorado (state #1), Wyoming (state #2), Kansas (state #3), and **Nebraska (state #4, complete)**, consolidated into one list. This is the canvass a new state runs against — per the standing rule (KS log, session 7): check every item below explicitly present/absent for the new state, run the canvass twice, don't treat a single pass as sufficient. When a new state is completed, its own findings get folded into this list before the next state starts, so this file keeps growing.

**How to use this:** for each row, determine the new state's status (Present / Confirmed Absent / Not Yet Checked) with a primary-source citation either way. "Not on the list yet" is not an acceptable end state for any row once a state is declared complete.

## Instructions for the next state

1. Copy this table (or work directly from it).
2. For every row, produce Present / Confirmed Absent with a primary-source citation, or explicitly write "Not Yet Checked" if a first pass doesn't get to it — never leave a row silently blank.
3. Run the full canvass a second time before declaring the state complete, independent of the first pass. Nebraska's second pass caught two genuine misses from the first — smoke detector and carbon monoxide alarm statutes — neither of which sits inside the core landlord-tenant title, so the second pass deliberately looked outside that chapter. Do the same for the next state: check adjacent titles (fire marshal/building code, consumer protection, criminal code) not just the core landlord-tenant act.
4. Add any new topics the state's own core-landlord-tenant-statute reading surfaces as new rows in the correct section above (or a new section, if it doesn't fit an existing one) — the next state after this one needs to see it too. Nebraska added four: the fast-track violent-crime eviction ground, the free-standing abandoned-property chapter architecture, the 5-year-lease exclusion, and the smoke-detector/CO-alarm building-safety section.
5. Update this file's per-state columns and hand it forward.
6. **Watch for overconfident secondary sources.** This project has now hit the same pattern four times independently — Wyoming (Hemlane), Kansas (a fabricated statute citation), and Nebraska twice (an overstated service-animal-fraud penalty, and a returned-check-fee cap that turned out to govern payday loans, not leases, plus a separate mischaracterization of a criminal bad-check restitution figure as a civil NSF fee cap). Treat any specific number, penalty, or citation from a non-primary source as unverified until checked against the actual statute text, regardless of how confidently it's stated or how many sources repeat it.
7. **Check adjacent chapters, not just the core act.** Nebraska's smoke-detector and CO-alarm duties, and its bad-check restitution statute, all live outside Chapter 76 (the core landlord-tenant title) — in the Fire Marshal, criminal code, and other adjacent chapters. A first pass confined to the core act's table of contents will miss these. Kansas's service-animal-fraud statute (Chapter 39) was the first instance of this pattern; Nebraska is the second and third.
