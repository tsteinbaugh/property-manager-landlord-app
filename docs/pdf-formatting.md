# Lease PDF formatting

*Split out of the bracketed-prompts work (Taylor, 2026-11-26): its own effort, scheduled by Taylor. Nothing built.*

## What it is
Some laws decide how lease text looks or where it goes, not only what it says: a minimum type size, bold or capitals, placement on the first page or beside the signature, the same page as another term, or a separate document signed apart from the lease. Today the PDF (`backend/src/lib/generateLeasePdf.js`) prints every clause the same way, in 11-point regular type. This effort makes the PDF follow those rules.

## Known gap to weigh when scheduling
Colorado's `habitability-notice-co` and `habitability-rights-statement-co` are Required, and C.R.S. § 38-12-505(3) requires each in at least twelve-point bold-faced type. Today's PDF prints them in 11-point regular.

## Scope
1. **Type and emphasis:** a minimum size, bold, capitals or underlining for a clause or one sentence. Some Texas clauses are effective only if bold or underlined, so the format decides whether the clause works at all.
2. **Placement:** the first page (with M.12, the first-page layout in `docs/backlog.md`), immediately above the signature, or the same page as another term.
3. **Separate documents:** a disclosure the law wants signed apart from the lease (Colorado's radon disclosure and parking rules, Florida's flood disclosure). The lease clause records receipt; whether the app generates the document itself is a decision for this effort.
4. **How a clause carries its format:** a small file keyed by clause id, guarded so every id exists and every rule cites its statute, read by the PDF. Not a column in `lease-clauses.csv` (it would change every state's delta format).

## How the brackets work hands over
Each state's bracket pass takes its formatting brackets out of the clause text, so they stop printing, and moves each one here with its statute. Until a state's pass, its brackets still print (as today). Nothing is lost: the list below is the record.
